## The question / brief
_The original brief was not in my files; this is reconstructed from the submission._

Tableau Visual Analytics assignment: build an interactive dashboard from the provided dataset that answers the business questions with appropriate chart types, KPIs, filters and annotated insights (here: employee recognition data).


## What I did
Interactive Tableau dashboard on 1,226 employee recognitions: KPI tiles, 3-year volume/value trend with forecast, reward-value distribution, recognitions by department vs average, a business-unit x recognition-type heatmap and an India state map of volume x satisfaction.
