# From Sample to Decision: Amazon India Order Values

**Course:** Statistical Methods for Decision Making (SMDM-2)  
**Programme:** PGPM 2026-27, Great Lakes Institute of Management, Term 2 (Jul-Aug 2026)  
**Type:** Group project (team members are credited inside the submission)  
**Skills:** Statistical inference, sampling, t-tests, AI-assisted analysis

## The question / brief
_Summarised from the course brief._

Mini project 'From Sample to Decision': pick a real dataset and apply Sessions 1-6 with Antigravity skills:

draw a random sample and compute point estimates and SE; build and interpret confidence intervals (CLT); frame H0/Ha; explain Type I/II errors and sample size; apply both critical-value and p-value rules; run one-sample, independent and paired t-tests; turn the output into a managerial recommendation and verify the AI's work.


## What I did
Does Amazon.in's average order value match finance's planning figure, and does it differ by fulfilment channel? Used 118,833 orders from the public Kaggle Amazon Sale Report (2022): random sampling, confidence intervals, hypothesis framing, power analysis and t-tests, all executed through AI-agent skills and verified by the team.
