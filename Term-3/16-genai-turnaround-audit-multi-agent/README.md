# Turnaround Audit Assistant: Multi-Agent Skills System

**Course:** Introduction to Generative AI  
**Programme:** PGPM 2026-27, Great Lakes Institute of Management, Term 3 (Aug-Sep 2026)  
**Type:** Individual  
**Skills:** Agentic AI, skill design, Python

## The question / brief
_The original brief was not in my files; this is reconstructed from the submission._

Classwork brief: 'Smita, an MBA student preparing a turnaround strategy presentation on an underperforming retail company, needs a 360-degree audit from a 100-page annual report.' Build a skills-based multi-agent assistant that produces the financial, market and risk analysis and one consolidated briefing.


## What I did
Multi-agent assistant that turns a company annual report into a 360-degree turnaround audit: three skills (financial audit, market intelligence, risk assessment) each with SKILL.md, reference thresholds, report templates and Python scripts (ratios, benchmark gaps, risk scores), an orchestration workflow, and sample outputs for a fictional RetailCorp.
