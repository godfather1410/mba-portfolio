# One Prompt, Five Reports: Token-Efficient Sales Analytics

**Course:** Introduction to Generative AI  
**Programme:** PGPM 2026-27, Great Lakes Institute of Management, Term 3 (Aug-Sep 2026)  
**Type:** Individual  
**Skills:** Prompt engineering, LLM workflow design

## The question / brief
_Summarised from the course brief._

Given a company sales dataset, design one reusable prompt that, when the data is loaded into ChatGPT, generates five predefined management reports (executive summary, regional performance, product performance, salesperson performance, five data-backed management insights) accurately and consistently while using as few prompt tokens as possible.


## What I did
Designed one reusable, token-minimised prompt that makes an LLM produce five management reports from a sales dataset by chaining roles (regional analyst, product analyst, ... strategist), each handing its finished report to the next; with design rationale and token trade-offs.
