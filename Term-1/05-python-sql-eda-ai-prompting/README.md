## The question / brief
_Summarised from the course brief._

Python & SQL assessment on raw customer and order tables (e.g. how many income values are missing, which city has most customers, row counts per table).

AI component: 'You have been given a business dataset with no documentation. Write a comprehensive prompt you would give an AI assistant to perform a complete Exploratory Data Analysis' - once for Python and once for SQL - detailed enough that another analyst using it would run a thorough, consistent EDA.


## What I did
Answers to the Python and SQL data assessments (missing values, customer distribution, row counts on raw customer/order tables) and an AI component: designing a comprehensive, reusable prompt that makes an AI assistant run a complete EDA in Python and in SQL (data quality, statistical profile, business insights, edge cases).
